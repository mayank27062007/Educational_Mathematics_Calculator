# 📘 Educational Mathematics Calculator (EMC)

The **Educational Mathematics Calculator (EMC)** is a lightweight, chapter-specific computational tool designed to help **secondary school students** understand and apply mathematical concepts more effectively. Unlike traditional calculators, EMC is tailored to support curriculum-based operations, offering both speed and accuracy in an intuitive interface.

## 🎯 Purpose

The EMC project was developed with the goal of **bridging the gap between theoretical understanding and practical problem-solving** in mathematics. It enhances the learning experience by:
- Providing context-sensitive calculations based on specific chapters.
- Validating user input and offering meaningful error messages.
- Enabling teachers to generate problems and verify answers quickly.

---

## 🛠 Features

- ✅ **Chapter-Specific Operations**  
  Focused modules based on secondary school math curriculum topics.

- 🎨 **Custom Interface**  
  Designed for simplicity and clarity, with easy navigation and instant feedback.

- ⚠️ **Input Validation & Error Handling**  
  Ensures correctness and provides helpful guidance when input is invalid.

- ⚡ **Fast & Lightweight**  
  Written in **C** and compiled to a minimal `.exe` file for Windows—no installation needed.

- 👨‍🏫 **Teacher-Friendly**  
  Automates problem generation and checking to assist classroom instruction.

---

## 🧑‍💻 Technologies Used

- **Language:** C
- **Platform:** Windows
- **Output:** Executable (.exe)

## 🚀 Getting Started

1. **Download the `.exe` file** from the `dist/` folder or build from source using a C compiler (e.g., GCC).
2. **Run the program** directly—no installation required.
3. **Choose a chapter/module** from the options.
4. **Follow on-screen instructions** to perform calculations.
